How it works

01 · The idea

A satellite cannot trust a cost sheet written on a laptop.

A satellite that runs AI onboard must decide, frame by frame, how much of a small and shifting energy, memory and time budget each inference deserves.

MIZAN (ميزان, Arabic for balance) weighs accuracy against the energy and time it costs, using costs measured on the board it runs on, and keeps correcting them while it flies. Its safety filter can refuse a configuration but never chooses one.

Three choices per frame

Model depth
Exit early from a MobileNetV3-Small network when it is confident; go deeper when it is not.
Frame frequency
Run or skip a frame, weighed by its value: clear land is worth more than cloud, ocean or night.
Input quality
Process the image at 48 or 64 pixels.

How MIZAN decides, every frame

  1. 1

    Observe state

    Battery, temperature, deadline, memory and the value of the frame.

  2. 2

    Propose configuration

    The most valuable option the energy price allows, from the corrected menu.

  3. 3

    Safety veto

    Refuse anything whose bound breaks the deadline, battery or heat limit. It can veto; it never chooses.

  4. 4

    Execute

    Run the chosen exit and resolution on the board, or skip the frame.

  5. 5

    Measure actual cost

    Time what the board really took.

  6. 6

    Update the cost menu

    Fold measured over predicted into a conformal latency bound for the next frame.

05 · Paper

MIZAN: Measure-First Adaptive Inference for Energy-Constrained Satellite Payloads

Ahmed Hedhili, Salem Essid, Ahmed Mnasri · IASTAM 6.0

We test the three levers an adaptive inference system has on a satellite: which model to run, how often to run it, and how much detail to process.

The model lever saves 52–57 % of energy per inference only on saturated accelerators. A laptop-profiled menu is 6.5× optimistic on the Raspberry Pi 4B, and correcting it online cuts missed deadlines by 49 % on the board. In a pre-registered held-out evaluation the system caused no breach in 100 simulated runs, but lost quality under heat; a rule written afterwards that steps down instead reaches 94.3 % on fresh seeds, above every fixed option.
