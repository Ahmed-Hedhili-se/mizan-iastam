# MIZAN · IASTAM 6.0

Online showcase for MIZAN, measure-first adaptive inference for energy-constrained satellite payloads.
Team INTERSTELLAR, SUP'COM, University of Carthage, Tunisia.

Live: https://ahmed-hedhili-se.github.io/mizan-iastam/

Static site, no build step. GitHub Pages: Settings › Pages › Deploy from a branch › main › / (root).

All files sit at the top level of the repository (no folders), so they can be uploaded in one go through the GitHub web page.
